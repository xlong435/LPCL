# 创想起源 · LPCL

LPCL 是一个面向 Minecraft: Java Edition 的免费 Windows 第三方启动器。

## 功能
- 微软正版 / LittleSkin / 离线登录
- 游戏版本下载与启动
- 整合包导入（Modrinth / CurseForge）
- 模组、材质、数据包、地图、光影下载
- 版本隔离
- 皮肤与披风设置

## 正版验证
LPCL 使用 Microsoft 官方 OAuth 设备代码流程，只验证玩家自己拥有的
Minecraft Java 版账号。不共享账号、不绕过正版验证、不分发游戏本体。
